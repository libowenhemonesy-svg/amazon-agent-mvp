# 数据导入模块彻底下线设计

## 目标

从产品界面和 FastAPI 服务中移除数据导入模块，历史数据库数据保持不变。

## 删除范围

- 移除侧边栏“数据导入”入口、`page-imports` 页面和其专属样式。
- 移除前端上传事件绑定、拖放处理和上传请求代码。
- 取消注册 `/imports` 路由，删除 `app/routes/imports.py`。
- 删除仅覆盖 `/imports/*` 接口的测试。

## 保留范围

- 保留 `app/importers/tabular.py` 与其单元测试；演示数据加载仍依赖该解析器。
- 保留样例数据、数据库表和既有业务数据；不执行数据删除或迁移。
- 依赖导入接口构造测试数据的测试改为直接使用 Repository 写入数据，避免继续依赖已下线接口。

## 成功标准

- 首页不再出现数据导入入口或 `page-imports` 页面。
- `/imports/sku` 等原接口返回 404。
- 演示数据加载和每日分析相关测试仍可运行。
- 前端加载不因删除的元素或函数产生 JavaScript 错误。
